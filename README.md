# Hyper-Chaotic Image Encryption Implementations in MATLAB

This repository contains MATLAB implementations of chaos-based image cryptographic systems derived from included academic research literature. 

---

## Overview

The scripts implement secure image encryption and cryptanalysis routines utilizing chaotic and hyper-chaotic dynamic systems:
* **4D Hyper-Chaotic Image Encryption & Cryptanalysis:** Based on traditional hyper-chaotic keystream mixing and image row/column shuffling, alongside chosen-plaintext/ciphertext attack scripts.
* **5D Hyper-Chaotic Parallel Image Cryptosystem:** A high-performance parallel image encryption scheme leveraging a 5-dimensional hyper-chaotic system with cubic nonlinear terms.

---

## Requirements

* **MATLAB** (R2012b or newer recommended)
* **Signal Processing Toolbox** (required for sequence processing and correlation analyses)

All scripts are completely implemented and **ready to run** out-of-the-box once MATLAB and the required toolbox are installed.
